## Daftar fitur
- 4 halaman saling terhubung dengan navigasi yang sama: Beranda, Tentang, Katalog, Kontak
- Beranda: hero (judul, tagline, tombol), ringkasan, dan 3 keunggulan
- Tentang: profil, visi dan misi, foto, serta tabel riwayat pendidikan
- Katalog: 6 proyek dalam bentuk kartu (gambar, nama, deskripsi, kategori)
- Kontak: alamat, media sosial, peta Google Maps, dan formulir dengan validasi HTML5
- Satu file CSS eksternal dengan variabel CSS, flexbox, grid, media query (HP dan desktop), efek hover, transition, dan `@keyframes`
- Bonus JavaScript: menu hamburger, validasi formulir dengan pesan di bawah kolom, serta filter dan pencarian katalog
